A tiny Python program that writes one roast of my fridge — a single line, at most 200 characters — to `/output/entry.txt`. Pure standard library, fully deterministic: the same line every run.

> My fridge hums a lullaby to leftovers it plans to murder by Friday, then beeps at me like I'm the intruder.

## Run it

```sh
python3 main.py
```
